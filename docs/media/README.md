# Promo Open Faktury

Exporty připravené 22. 10. 2026:

- `open-faktura-promo.mp4`: české promo, 76 sekund, Full HD, 30 snímků/s, H.264 a původní instrumentální podkres.
- `open-faktura-preview.gif`: tichá smyčka přibližně 25 sekund, 800 × 450, 10 snímků/s a 2,3 MB pro zobrazení přímo v kořenovém README na GitHubu.

Záběry pocházejí ze skutečného produktového webového rozhraní připojeného
k běžícímu Rust API a samostatné PostgreSQL databázi. Účetní doklady, kontakty
i ostatní data jsou syntetická, vytvořená pouze pro promo. PDF a QR platbu
vygenerovala aplikace. Ukázka skills a dokumentace obsahuje skutečné soubory
z `.agents/skills` a `docs`; okolní panel je součástí grafiky videa.

Video zachycuje přehled, fakturaci, PDF, nabídky, zálohy, pravidelné faktury,
banku, pokladnu, prodejky, nákupy, inbox, ceník, sklad, reporty, kontakty,
import a nastavení vzhledu. Závěr zdůrazňuje AGPL v3, vlastní provoz,
skills, dokumentaci a REST API/MCP. Projekt je ve videu označený jako vyvíjený.
Přehledy nejsou prezentované jako daňové přiznání.

Zdrojový Remotion projekt, jeho npm závislosti a nástroje pro pořizování
záběrů jsou záměrně mimo tento repozitář. Remotion není součástí aplikace,
jejího sestavení ani instalačních balíčků. Zde jsou pouze hotové výstupy.
